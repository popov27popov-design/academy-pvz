# Академия ПВЗ — R0

Демо-прототип сайта и учебного сценария по ТЗ v1.1. Реализован маршрут: каталог → регистрация/вход → демонстрационный доступ → урок → тест → образец PDF-сертификата и проверка QR.

## Запуск

Требуется Node.js 22.13+ (используется встроенный `node:sqlite`) и Python с зависимостями из `requirements.txt` и шрифтом DejaVu Sans (или настройкой `ACADEMY_FONT_PATH`) для PDF/QR. Установите зависимости командой `python -m pip install -r requirements.txt`.

```bash
node server.mjs
```

Откройте `http://localhost:3000`. База SQLite создаётся рядом с сервером. Для размещения за публичным HTTPS прокси задайте `PUBLIC_BASE_URL=https://ваш-домен`; TLS, secure-cookie, защита от CSRF, секреты, резервные копии и эксплуатационный мониторинг ещё не настроены. Этот прототип не предназначен для реальных платежей и сбора реальных персональных данных.

## Границы R0

- Оплата, тарифы и реальный checkout отключены: цены в исходном ТЗ не утверждены, выбор продавца, платёжного провайдера и фискальной модели остаётся BLOCKER.
- Учебный материал — только демонстрационный, не утверждённая инструкция маркетплейса.
- Прохождение в R0 использует один демо-урок и 5 вопросов; коммерческие параметры аттестации остаются предложением.
- Сертификат явно маркирован как демо-образец и не является государственным документом или официальным допуском.
- Административная панель, корпоративные роли и назначение B2B пока не реализованы.
